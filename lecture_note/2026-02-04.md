# 📚 강의 노트 (2026-02-04)

## 📌 강의 핵심 요약
- **데이터 관계 및 SQL 기본**: `Chinook` 샘플 DB를 활용하여 아티스트(Artist), 앨범(Album), 트랙(Track) 간의 관계형 데이터 모델링과 ERD 구조를 학습했습니다.
- **실무형 데이터 수집 및 자동화**: 공공데이터 API를 활용해 응급실 실시간 데이터를 수집하고, 이를 초경량 자동화 툴인 **n8n(엔팔엔)**과 **Supabase(슈퍼베이스)**에 적재하는 과정을 실습했습니다.
- **AI 에이전트 및 MCP 연동**: AI의 기능 확장을 위한 **MCP(Model Context Protocol)**의 개념을 이해하고, AI가 도구를 직접 호출하여 정보를 검색하거나 노션과 연동하는 실전 기술을 다뤘습니다.

---

## 📚 상세 내용 정리

### 1. 관계형 데이터베이스와 ERD (Chinook DB)
- **개념 설명**: 데이터 간의 연결 고리를 이해하는 것이 중요합니다.
  - **PK(Primary Key)**: 각 테이블의 고유 식별자 (예: `ArtistId`)
  - **FK(Foreign Key)**: 다른 테이블을 참조하는 키 (예: `Album` 테이블의 `ArtistId`)
- **실습/예시**:
  - `Artist` → `Album` → `Track` 계층 구조 이해.
  - 아티스트별 앨범 개수 파악을 위한 논리적 흐름 분석.
- **팁**: SQL을 직접 짜지 못하더라도 AI에게 데이터 간의 관계(Schema)를 설명할 수 있으면 원하는 데이터를 효율적으로 추출할 수 있습니다.

### 2. n8n(엔팔엔)을 활용한 데이터 파이프라인 구축
- **핵심 이론**: 에어플로우(Airflow)보다 가벼운 자동화 워크플로우를 구축합니다.
- **실습 내용**:
  - **수집**: 국립중앙의료원 전국 응급의료기관 정보조회 API 활용.
  - **가공**: JSON 데이터를 적절히 파싱하여 필요한 항목만 추출.
  - **적재**: n8n을 통해 Supabase 테이블에 실시간 데이터를 자동 적재.
- **팁**: 데이터 분석에서 가장 시간이 많이 걸리는 수집과 정제 과정을 n8n으로 자동화할 수 있습니다.

### 3. AI 에이전트 및 MCP(Model Context Protocol) 가이드
- **개념 설명**: 
  - **MCP**: AI 모델이 외부 도구나 데이터 소스(API, DB, Notion 등)에 직접 접근할 수 있게 해주는 표준 규약입니다.
  - **에이전트**: 단순히 답변만 하는 것이 아니라, 특정 작업을 수행하기 위해 도구를 사용하는 주체입니다.
- **실습 과정**:
  - Anthropic의 `Claude` 환경에서 MCP 서버를 연결하는 설정 과정 실습.
  - `get_pokemon` 툴을 사용하여 AI가 실시간으로 포켓몬 정보를 가져오도록 연동.
- **주의사항**: MCP 연동 시 토큰 소비가 많을 수 있으므로 필요한 툴만 적절히 연결하여 테스트해야 합니다.

## 💡 핵심 포인트
- **데이터 리터러시**: 데이터를 단순히 보는 것이 아니라, 그 이면의 패턴(예: 응급실 병상 수의 마이너스 의미 등)을 읽어내는 능력이 중요합니다.
- **트리거-태스크-타겟(Trigger-Task-Target)**: n8n 워크플로우 설계 시 "언제 실행되는가(Trigger)", "무엇을 하는가(Task)", "어디로 보내는가(Target)"의 구조를 명확히 하는 것이 핵심입니다.

## 🔗 관련 키워드
- **n8n (엔팔엔)**: 초경량 워크플로우 자동화 도구.
- **Supabase (슈퍼베이스)**: 오픈소스 Firebase 대안이자 PostgreSQL 기반의 BaaS.
- **MCP (Model Context Protocol)**: AI 에이전트 기능 확장을 위한 최신 인프라.
- **ERD (Entity Relationship Diagram)**: 데이터베이스 개체 간의 관계를 설계하는 다이어그램.
- **Poreign Key (외래 키)**: 테이블 간의 연결 고리(연결 고리 이론).
