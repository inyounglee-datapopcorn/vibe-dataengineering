## 1. n8n 핵심 가치: 왜 n8n인가? (Why n8n?)

### 💡 한 줄 요약
**"Zapier의 강력함과 코딩의 유연성을 결합한, 가장 가성비 좋은 엔터 프라이즈급 자동화 툴"**

### 🧩 Zapier/Make vs n8n
| 구분 | Zapier / Make | n8n (Self-hosted) |
| :--- | :--- | :--- |
| **비용** | 실행 횟수당 과금 (비쌈) | **설치형은 무료** (서버비만 발생) |
| **데이터 보안** | 클라우드사에 데이터 노출 가능성 | **데이터 주권 100%** (내 서버에 저장) |
| **유연성** | 정해진 기능만 가능 | **JavaScript/Python 코딩**으로 무한 확장 |
| **난이도** | 쉬움 (입문용) | 중간 (전문가용) |

## 2. 설치 및 운영 환경 (Hosting)

n8n은 어디에 설치하느냐에 따라 활용도가 달라집니다.

1.  **n8n Cloud (유료)**: 가장 빠르고 안정적입니다. 복잡한 설정 없이 바로 시작할 수 있습니다.
2.  **Self-Hosting (Docker)**: 개인 PC나 클라우드 서버(AWS, Oracle Cloud 등)에 직접 설치합니다. 전문가들이 가장 선호하는 방식입니다.
3.  **Railway (추천)**: 도커 설정이 어려운 초보자에게 추천하는 클라우드 배포 방식입니다. 저렴한 월 관리비로 24시간 안정적으로 구동할 수 있습니다.

## 3. 실전 핵심 노드 활용법 (Key Nodes Mastery)

n8n의 수백 개 노드 중, 이것만 알아도 80%는 해결됩니다.

### ① 데이터 수집 (Gathering)
- **HTTP Request**: 외부 API와 소통하는 핵심 노드. (날씨 정보 가져오기, 슬랙 메시지 보내기 등)
- **HTML Extract**: 웹사이트의 HTML을 분석하여 뉴스 제목, 가격 정보 등을 긁어오는 '크롤러' 역할을 합니다.

### ② 데이터 처리 (Logic)
- **Code (JS/Python)**: 노드만으로 해결 안 되는 복잡한 계산이나 데이터 가공을 직접 코딩합니다.
- **If / Switch**: "제목에 '삼성'이 포함되어 있으면 A채널로, 아니면 B채널로" 같은 조건부 로직을 짭니다.
- **Filter / Sort**: 필요한 데이터만 골라내거나 순서를 정렬합니다.

### ③ 데이터 결합 및 제어 (Advanced)
- **Merge**: 서로 다른 곳에서 온 두 데이터를 하나로 합칩니다. (예: 주식 가격 + 뉴스 기사)
- **Wait**: 다음 작업을 하기 전 일정 시간을 기다립니다. (API 요청 제한 방지)
- **Loop Over Items**: 100개의 데이터를 하나씩 순차적으로 처리할 때 사용합니다.

## 4. AI 에이전틱 자동화 (AI & Agentic Workflows)

n8n이 최근 가장 강력해진 이유입니다. **"생각하는 자동화"**를 만들 수 있습니다.

### 🤖 AI 에이전트 구성 요소
- **AI Agent Node**: OpenAI, Claude, Gemini 등 LLM을 에이전트의 두뇌로 연결합니다.
- **Memory**: 과거 대화 내용을 기억하여 연속적인 대화(Thread)가 가능하게 합니다.
- **Tools**: AI가 대화 도중 직접 '검색'하거나 '파일을 읽도록' HTTP Request나 Google Search 기능을 도구로 쥐여줍니다.

## 5. 운영 안정성 (Production Readiness)

실제로 서비스를 돌린다면 반드시 챙겨야 할 포인트입니다.

- **Error Notification**: 워크플로우가 실패했을 때 즉시 나에게 슬랙이나 이메일로 알림을 주도록 설계해야 합니다.

## 1. n8n이란 무엇인가? (Definition)

### 💡 한 줄 요약
**"모든 앱과 데이터를 연결하는 디지털 레고 블록 (Workflow Automation Tool)"**

### 🧩 비유로 이해하기
여러분이 레고 블록을 조립해서 성을 만드는 것처럼, n8n은 **"구글 시트 블록"**, **"슬랙 블록"**, **"ChatGPT 블록"**을 선으로 연결해서 **"일하는 로봇(Workflow)"**을 만드는 도구입니다.

- **기존 방식**: 파이썬으로 `requests` 라이브러리를 쓰고, `cron`으로 스케줄링하고, 에러 로그를 직접 파일에 남겨야 함 (진입 장벽 높음 🤯)
- **n8n 방식**: 화면에 노드(점)를 찍고 선으로 연결하면 끝. 데이터가 흘러가는 게 눈에 보임 (직관적 😎)

## 2. 왜 지금 'n8n'인가? (Why Now?)

취준생과 현직자가 2026년에 n8n을 반드시 주목해야 하는 3가지 이유가 있습니다.

### ① AI와의 완벽한 궁합 (Best for AI)
n8n은 다른 자동화 툴(Zapier, Make)보다 **AI 통합(LangChain)** 기능이 압도적으로 강력합니다. 단순히 GPT를 호출하는 것을 넘어, **Vector Store(Pinecone)**나 **Memory** 기능을 노드 하나로 붙일 수 있습니다.
- **예시**: "매일 아침 뉴스 읽고 → 요약해서 → 내 카카오톡으로 보내줘" (이걸 10분 만에 만듭니다)

### ② 강력한 커스터마이징 (Developer Friendly)
노코드(No-Code) 툴이지만, 필요하면 코드를 쓸 수도 있습니다. "Fair-code"라는 철학을 가지고 있어 개발자 친화적입니다.
- 초보자는 **드래그 앤 드롭**으로 90%를 해결합니다.
- 개발자는 **JavaScript/Python** 노드를 섞어서 나머지 복잡한 10% 로직(데이터 정규화, 암호화 등)을 척척 해결합니다.

### ③ 비용 효율성 (Cost Effective)
- **Zapier**: 비쌈. 태스크(Task) 건당 과금이라 조금만 써도 월 10만 원이 훌쩍 넘습니다.
- **n8n**: **Self-hosted(설치형)** 버전을 쓰면 **공짜**로 무제한 사용 가능합니다. 내 노트북이나 저렴한 클라우드(VPS)에 띄우면 됩니다.

## 3. n8n 핵심 용어 정리 (Core Concepts)

n8n을 켜자마자 보게 될 단어들입니다. 이 4가지만 알면 80%는 이해한 것입니다.

### 🔹 Workflow (워크플로우)
- 전체적인 작업의 흐름. "지도(Map)"라고 생각하세요.
- 하나의 워크플로우 파일(`.json`)은 공유하기도 쉽습니다.

### 🔹 Node (노드)
- 워크플로우를 구성하는 각각의 **"블록"**입니다.
- **Trigger Node (방아쇠)**: 워크플로우를 시작시키는 노드. (예: `Schedule`(매일 9시), `Webhook`(요청이 오면), `App Event`(새 이메일 도착 시))
- **Regular Node (행동)**: 실제 일을 하는 노드. (예: `HTTP Request`, `Google Sheets`, `OpenAI`)

### 🔹 Connection (Credential)
- 외부 서비스(Google, Slack, Notion)를 사용할 때 필요한 **"출입증(로그인)"** 정보입니다.
- OAuth2 인증도 클릭 몇 번으로 처리해주며, 한 번 등록해 두면 모든 워크플로우에서 꺼내 쓸 수 있습니다. **보안상 매우 안전하게 관리됩니다.**

### 🔹 Execution (실행 데이터)
- 워크플로우가 실제로 돌아간 **"기록"**입니다.
- **성공(Success)** 초록색, **실패(Error)** 빨간색으로 표시됩니다.
- 각 노드별로 들어오고 나간 JSON 데이터를 상세히 볼 수 있어 **디버깅(Debugging)**의 핵심이 됩니다.

## 4. n8n vs Zapier vs Make (비교 분석)

면접관이 "왜 굳이 n8n을 썼나요?"라고 물어볼 때, 이 표를 머릿속에 그리며 답하면 됩니다.

| 특징 | n8n | Zapier | Make (Integromat) |
| :--- | :--- | :--- | :--- |
| **비용** | **무료 (설치 시)** / 유료 | 비쌈 (건당 과금) | 적당함 |
| **데이터 보안** | **데이터 주권 100%** (로컬/자체 서버) | 클라우드사 의존 | 클라우드사 의존 |
| **유연성** | **코드(JS/Python)로 무한 확장** | 제한적 | 중간 |
| **AI 기능** | **최상 (LangChain 네이티브)** | 중 | 중 |
| **추천 대상** | **AI 에이전트 개발자**, 데이터 엔지니어 | 비개발자, 마케터 | 디자이너, 복잡한 로직 설계자 |

## 5. [심화] 데이터 구조와 표현식 (Deep Dive)

n8n이 개발자들에게 사랑받는 이유는 데이터를 다루는 방식이 **투명**하기 때문입니다.

### 🧬 JSON 데이터 구조
n8n의 모든 데이터는 **JSON(JavaScript Object Notation)** 형태로 흐릅니다.
- **Input**: 이전 노드에서 `{ "name": "Popcorn", "role": "Engineer" }` 라는 JSON을 받습니다.
- **Output**: 다음 노드로 `{ "message": "Hello Popcorn" }` 이라는 JSON을 넘깁니다.
- 엑셀처럼 "테이블"이 아니라, "객체의 리스트"로 처리된다는 점을 명심하세요.

### 📌 Pin Data (데이터 고정)
개발할 때 매번 API를 호출하면 느리고 돈이 듭니다.
- 결과 데이터를 **Pin(고정)** 해두면, 노드를 실행하지 않고도 그 데이터를 계속 재사용하며 다음 단계를 개발할 수 있습니다. (꿀기능 🍯)

### 🧮 Expressions (표현식)
노드 설정창에서 `{{ ... }}` 안에 변수를 넣어 동적으로 값을 바꿀 수 있습니다.
- **기본**: `{{ $json["name"] }}` -> 현재 노드 들어온 데이터 중 'name' 값
- **다른 노드 참조**: `{{ $node["Webhook"].json["body"]["id"] }}` -> 'Webhook' 노드의 결과값 중 'id'
- **자바스크립트**: `{{ $json["text"].toUpperCase() }}` -> 텍스트를 대문자로 변환

## 6. 필수 노드 완전 정복 (Essential Nodes)

수백 개의 노드가 있지만, 이 5개만 알면 웬만한 건 다 만듭니다.

### ① Webhook (웹훅)
- **역할**: 외부에서 내 워크플로우를 호출할 수 있게 "URL 주소"를 만들어줍니다.
- **용도**: 슬랙 봇, 나만의 API 서버 만들기, 깃허브 알림 받기.
- **Test vs Production**: 테스트 URL과 배포용 URL이 따로 있으니 주의하세요!

### ② Set (변수 설정)
- **역할**: 필요한 데이터만 골라내거나(Keep Only), 새로운 필드를 추가할 때 씁니다.
- **용도**: "API 결과가 너무 지저분해. 필요한 3개 필드만 남기자."

### ③ HTTP Request (만능 통신)
- **역할**: n8n에 공식 노드가 없는 서비스(예: 한국 공공데이터포털)와 통신할 때 씁니다.
- **용도**: GET, POST 요청 날리기. API 문서만 볼 줄 알면 세상 모든 데이터 연결 가능.

### ④ Code (코드)
- **역할**: JavaScript(또는 Python) 코드를 직접 실행합니다.
- **용도**: 복잡한 수학 계산, 정규식(Regex)으로 텍스트 추출, 날짜 포맷 변경 등 기본 노드로 하기 귀찮은 작업을 한 방에 해결.

### ⑤ If / Switch (분기 처리)
- **역할**: "참(True)"이면 위쪽 길로, "거짓(False)"이면 아래쪽 길로 보냅니다.
- **용도**: "내일 비가 오면(True) 우산 챙기라고 알림 보내고, 안 오면(False) 그냥 둬."

## 7. 실습: 나만의 첫 워크플로우 만들기 (Hands-on)

**목표**: "매일 아침 8시에 명언을 가져와서, 한국어로 번역해 슬랙으로 보내기"

1.  **Trigger**: `Schedule Trigger` 노드 추가
    - 설정: "Every Day", Hour: 8, Minute: 00
2.  **Action 1**: `HTTP Request` 노드 추가
    - URL: `https://api.quotable.io/random`
    - Method: GET
3.  **Action 2**: `Google Translate` 노드 추가
    - Text: `{{ $node["HTTP Request"].json["content"] }}` (이전 단계의 명언 내용)
    - Target Language: Korean (KO)
4.  **Action 3**: `Slack` 노드 추가
    - Authentication: 슬랙 계정 연결
    - Channel: 내 채널 선택
    - Text: `오늘의 명언: {{ $json["text"] }} - {{ $node["HTTP Request"].json["author"] }}`
5.  **테스트 & 활성화**:
    - `Execute Workflow` 버튼을 눌러 테스트해보고, 잘 되면 우측 상단 `Active` 스위치를 켭니다.

## 8. [고급] AI Agent Hub (The Real Power)

n8n의 꽃은 바로 **Advanced AI** 기능입니다. LangChain을 몰라도 RAG 에이전트를 만들 수 있습니다.

### 🤖 구성 요소
1.  **AI Agent Node**: 두뇌 역할. (Chat Model과 Tools를 연결)
2.  **Chat Model**: LLM 선택. (OpenAI GPT-4o, Anthropic Claude 3.5 Sonnet)
3.  **Window Buffer Memory**: 붕어 기억력 탈출. 이전 대화 내용을 기억하게 함.
4.  **Tools**: 에이전트가 사용할 도구. (Calculator, Wikipedia, Custom Tool)

### 🚀 시나리오: 사내 문서 기반 Q&A 봇 (RAG)
- **준비물**: `OpenAI Model`, `Pinecone Vector Store`, `Google Drive`.
- **흐름**:
    1.  사용자가 질문을 던짐 (Webhook/Chat Trigger).
    2.  Agent가 질문과 관련된 사내 문서를 Pinecone에서 검색 (**Retrieval**).
    3.  검색된 내용 + 질문을 섞어서 GPT에게 전달.
    4.  GPT가 근거 있는 답변을 생성 (**Generation**).
- **결과**: "우리 회사 복지 포인트 언제 들어와?" 라고 물으면 매뉴얼을 찾아서 "매월 25일에 지급됩니다."라고 답함. (Notion이나 PDF 뒤질 필요 없음!)

## 9. 실무자 Tip: 에러 처리 및 배포

### 🚨 에러 처리 (Error Handling)
프로덕션 환경에서는 에러가 나면 조용히 멈추는 게 최악입니다.
- **Error Trigger**: 워크플로우가 실패했을 때만 실행되는 특별한 트리거입니다.
- **패턴**: 모든 워크플로우에 `Error Trigger -> Slack 알림`을 붙여두면, 밤새 에러가 나도 아침에 바로 알고 고칠 수 있습니다.

### ☁️ 설치 및 배포 (Self-Hosting)
내 컴퓨터에서만 돌리지 말고, 24시간 돌아가는 서버를 만드세요.
1.  **npm (로컬 테스트용)**
    ```bash
    npm install n8n -g
    n8n start
    ```
2.  **Docker (서버 배포용 - 추천)**
    ```yaml
    # docker-compose.yml
    version: '3.1'
    services:
      n8n:
        image: n8nio/n8n
        ports:
          - "5678:5678"
        volumes:
          - ~/.n8n:/home/node/.n8n
    ```
    - 터미널에서 `docker-compose up -d` 입력하면 끝. AWS 프리티어에서도 잘 돌아갑니다.
