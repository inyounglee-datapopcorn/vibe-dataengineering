수 : 유즈케이스 소개 (오전 1개, 오후 1개, 오후 3시 부터는 프로젝트 주제 선정 및 준비)목금 : AI Agent 데이터분석 프로젝트 기간.

분석 프로젝트 주제는 수업 때 말씀드린 것처럼
기획 -> 수집(정제) -> 분석 -> 시각화 -> 리포트가 모두 녹여지게 만들면 좋겠습니다.

기획 : 데이터분석 목적이 명확해야 함. (***가장 중요)수집(정제) : 목적에 맞는 데이터를 잘 가져오고 정제를 했는지. (Split Out, Edit Fields, Merge, Aggregate 등 사용)분석 : (프롬프팅) AI Agent 프롬프트를 명확히 정의하였고, (INPUT) Agent에게 보낼 형태로 데이터가 올바르게 잘 구성되었는지. (OUTPUT) Output Parser로 데이터 결과값을 원하는 구조로 받게 설정했는지시각화 : 데이터를 잘 이해할 수 있게 시각화 차트로 구현이 되었는지. (QuickChart 말고, 다른 시각화로도 가능함. ) 리포트 : 메일, 슬랙, 노션, 옵시디언, DB 등 저장소 혹은 커뮤니케이션 협업툴에 올바르게 보냈는지. - (이건 중요도가 높진 않습니다.)
